# 到梦空间发分程序（Linux）

程序通过 ADB 操作 Android 手机上的“到梦空间”App；电脑负责读取名单、保存进度和导出结果。程序按学生逐人发分，不使用批量发分。

## 安装

在 Ubuntu 上安装 Python 虚拟环境组件和 ADB：

```bash
sudo apt update
sudo apt install python3 python3-venv adb
```

然后在本目录执行：

```bash
chmod +x install-linux.sh run-linux.sh
./install-linux.sh
./run-linux.sh -h
```

依赖安装在本目录的 `.venv` 中。若 ADB 不在系统 `PATH` 内，可在运行前设置 `ADBUTILS_ADB_PATH` 为其绝对路径。

## 图形界面

图形界面和命令行是同一套流程，只是把参数填在窗口里，进度、日志和停止按钮也在窗口里：

```bash
.venv/bin/python -m pip install -r requirements-gui.txt
.venv/bin/python DM-gui.py
```

- 新建任务：选录取名单（0 分）和 1 分 / 2 分名单，首次连接勾选“初始化设备”
- 继续上次任务：选上次生成的结果文件夹，读其中的 `config.json` 和 `students.db`
- 显示总进度、当前分值的进度和实时日志
- “停止”会在处理完当前学生后停下，进度保留，之后可继续
- 结束后点“打开运行目录”查看导出的 Excel

手机上需要人工处理时（掉登录、需要重连、多次返回仍未到达目标页），窗口会弹窗等你操作完再继续。

装好以后可以把图标放到桌面和应用列表，点一下就打开：

```bash
./install-desktop.sh
```

之后不用记命令，直接点桌面上的「到梦空间批量发分」。仓库换了位置就重跑一次这个脚本。

在 Windows 上打包成 exe 执行 `build-windows.cmd`，产物在 `dist\daomeng-gui\`，整个目录拷到目标电脑即可运行。

## 准备名单和手机

手机上安装并登录“到梦空间”，打开 USB 调试并允许电脑连接。运行 `adb devices`，设备状态应为 `device`。请先完成目标学生的签到或补签，再启动发分。

录取名单为 `.xlsx`，须有“活动名称”“学号”“姓名”列。程序从“活动名称”列的第二条数据读取活动名，故至少要有两条数据。每份发分名单至少有“学号”“姓名”列。学号按 11 位文本处理；单元格开头多余的反引号会在读取时去掉。

## 发分

`0` 表示录取名单，`1` 和 `2` 分别表示两份发分名单的分值。根据实际文件路径修改命令：

```bash
./run-linux.sh \
  -f "/绝对路径/录取名单.xlsx" 0 \
  -f "/绝对路径/1分.xlsx" 1 \
  -f "/绝对路径/2分.xlsx" 2 \
  -i
```

`-i` 用于首次初始化手机上的 uiautomator2；后续通常可以省略。无线调试参数见 `./run-linux.sh -h`。

## 结果和恢复

程序在本目录创建“活动名-时间”结果文件夹，保存 `automation.log`、学生进度数据库和配置。正常完成后会导出一份包含每名学生状态的 Excel 文件。中断后使用原结果文件夹恢复：

```bash
./run-linux.sh -r "/绝对路径/活动名-时间文件夹"
```

恢复时保留原名单文件，不要再传 `-f`。只有状态为“未处理”的学生会自动继续。搜索时程序会等待目标姓名出现；两次查询仍无法确认的学生标记为“待核对”，不点击颁发。“待核对”“状态未知”等记录不会自动重发，应先在 App 中核对实际学分。结果以到梦空间活动页面的学分记录为准。

使用 `-u` 账号密码文件时，账号密码会保存在任务目录的 `config.json` 中，应妥善保管。
